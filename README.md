# SteadyTouch Website

Website für unsere Diplomarbeit **SteadyTouch** an der HTL Rennweg.

Gemacht mit Vue 3 + Vite.

## Starten

```
npm install
npm run dev
```

## Aufbau

- `src/components/NavBar.vue` - Header mit Logo und Navigation
- `src/components/Footer.vue` - Footer
- `src/views/Startseite.vue` - Startseite mit Projektbeschreibung und Fortschrittsbalken
- `src/router/index.js` - Routen

Den Fortschritt ändert man in `src/views/Startseite.vue` bei der Variable `fortschritt`.
